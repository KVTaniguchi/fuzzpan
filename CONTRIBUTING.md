# Contributing

Issues are welcome: bug reports, questions, and suggestions for how the board
could work better. Please do not include secrets, tokens, backups or real
family data in an issue.

**Outside code contributions are not accepted yet.** Pull requests will be
closed without review for now. This is not a judgement of the work: the project
has not settled how it will handle contributor agreements and the rights in
contributed code. This note will change when it does.

## Security problems

Do not file a public issue for a vulnerability. See [`SECURITY.md`](SECURITY.md)
for how to report it privately.
